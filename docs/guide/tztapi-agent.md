# tztapi-agent 中焯接口智能体

`tztapi-agent` 是中焯（TZT，tzt.cn）行情 3.0 接口的专家子智能体，内置官方接口文档（自包含，跨项目/跨机器可用）。本项目的 `AGENTS.md` 已声明派发规则：**凡是基于中焯行情 API 的接口需求——新建行情接口、校验现有接口用法、参数/响应解析问题——必须调用它**。

> 智能体仓库（私有）：`https://github.com/seuzxh/tztapi-agent`，本机安装在 `~/.zcode/skills/tztapi-agent/`。完整使用手册见其 [USAGE.md](https://github.com/seuzxh/tztapi-agent/blob/main/USAGE.md)。

## 三类场景

| 场景 | 你说什么 | 它做什么 |
|---|---|---|
| **新建行情接口** | "帮我加一个成交明细（10003）的获取方法" | 查官方文档 → 构造请求 → 真实 API 验证 → 交付请求/解析代码 |
| **校验现有接口** | "检查一下分时请求的参数传得对不对" | 逐参数对照文档 + 实测复核 → 映射表与偏差清单 |
| **接口咨询** | "514 是什么属性？百分比字段怎么换算单位？" | 查属性 ID 表/参数说明 → 带出处的答案（可实测验证的会实测） |

## 工作准则（铁律）

1. **文档为据**：一切结论以官方文档为据，答复注明出处（文件+章节），禁止编造属性 ID/参数名
2. **实测定论**：任何「可用/正确/确认」结论必须在本次任务中用真实 API 验证过
3. **结论分级**：每条结论带标签——【实测确认】/【文档确认】/【文档存疑】/【未验证】
4. **只读安全**：只发 GET 请求，限流 ≥0.1s，不改生产数据

## 怎么触发

- **自动派发（推荐）**：在本项目里正常提中焯接口需求即可，主智能体按 AGENTS.md 派发规则调用
- **手动**：ZCode 输入 `/tztapi-agent <需求描述>`；Claude Code 对话中点名 "用 tztapi-agent 子智能体处理"
- **包成 sub-agent**（重任务推荐，如全量接口审计）：派 general-purpose 子代理执行「先读 `~/.zcode/skills/tztapi-agent/SKILL.md` 及 `references/`，再执行任务」——过程不污染主对话上下文，完整 prompt 模板见 USAGE.md 方式三

## 交付物

1. 请求参数表（每项注明文档出处）
2. 响应结构与解析方法（键名、`{属性ID}[0]` 层级、单位换算：价格÷1e6=元、金额÷1e4=元、量=股、比例÷1e3、百分比÷1e5）
3. 代码——本项目内遵循 Fetcher 子类/单位转换/双层测试（mock 单测+integration 集成）模式，并同步更新 AGENTS.md、api-reference.md、CHANGELOG
4. 实测验证记录（含东财/新浪外部基准对照）
5. 已知限制与坑（如有）
