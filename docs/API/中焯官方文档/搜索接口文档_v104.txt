StockNameExt搜索规则
完全匹配
在所有市场中，搜索完全一致的股票代码。
模糊搜索
按照指定的市场号，或者市场号列表的先后次序模糊搜索股票代码、名称、拼音；
默认搜索顺序
搜索时，未指定具体的市场，或者股票分类时，采用默认的搜索顺序：
上证-A股（1-0-1）
上证-科创板（1-0-7）
深证-A股（0-0-1）
深证-中小（0-0-2）
深证-创业板（0-0-3）
北证-A股（103-0-1）
上证-CDR（1-6-1）
上证-科创板CDR（1-6-2）
深证-CDR（0-6-1）
深证-创业板CDR（0-6-2）
上证-B股（1-0-2）
深证-B股（0-0-4）
上证-基金（1-1）
深证-基金（0-1）
上证-其他（债券、权证、指数……，即大类由小到大的顺序）
深证-其他（债券、权证、指数……，即大类由小到大的顺序）
北证-其他（债券、权证、指数……，即大类由小到大的顺序）
配置文件中其他市场的配置顺序
输出排序规则
搜索结果的出参排序规则，总体上依据搜索时匹配到的先后顺序出参：
如果市场、大类、小类，其中一个不相同，则先搜到的股票排序在前
如果市场、大类、小类均相同，再判断搜索位置，若搜索位置相同，则按照代码的字符串由小到大排序；若搜索位置不相同，则搜索位置小的排序在前。
举例：
入参：
code=60000
出参：
600009|上海机场|600009|1|0|1|4353|100|沪A|160000|19深圳21||160000|1|2|1|4355|102|债券|
PS：600009排序在160000前面，因为关键字60000在600009中的搜索位置为0，在160000中的搜索位置为1。
此外，完全匹配的代码，出参时必定排序在最前。
配置说明
[Config]
CodeFilePath
加载Code文件路径


BlockFilePath
加载板块文件路径


CodeFileUpateTime
定时重新加载板块和代码表文件时间点


MaxReturnCount
最大返回搜索结果数目，最大300，默认128


SearchTztCode
搜索中焯股票代码,默认为1，表示搜索中焯行情内部使用代码，为0表示搜索通用股票代码


TztStockCode
当SearchTztCode=0时, 用中焯代码搜索板块指数(格式:市场号|市场号|…)


FindStockType
当完全匹配后是否继续搜,用于兼容2.0，只对32功能号有用，10032不处理这一配置项


AddStockNameSuffix
股票名称是否额外添加后缀,1-添加;0-不添加;默认为1，影响市场沪、深、新三板市场


OutMoudle
设置组件输出编码 0: gbk编码 1: utf8编码 默认1，影响组件编码和出参编码


UseHKDelay
是否使用港股延时数据, 0-不使用 1-使用 2-不使用延时数据但港股实时数据按权限显示,默认0，用于兼容2.0，只有一只港股代码时出参加UseHKDelay


[BlockSegment]
100 = 1-0-1
板块id=市场号-大类-小类 ,与入参BlockId匹配使用（10032使用，32用不到）。板块id概念与行情板块文件无关。
[MarketConfig]
1  = 国内股票-上证证券
市场号=代码表名称，限定加载代码表范围，这里有code路径没有代码表也不加载，code路径有代码表这里不配也不会加载对应市场

10032
StockCodeList
String
N
多个股票精确搜索（注意，仅可查找股票代码），同时可以选择是否指定对应的市场标识符；其中，股票和对应市场对使用|符号分隔，不同股票使用逗号分隔
例如：
StockCodeList=600000|1,600004|SHAccount,000001|SZAccount
PS：
该参数优先级最高，不再使用StockCode、BlockId、Segment、Market、BlockName入参进行搜索。
市场同时支持股东账号类型、market(3.0)。
当不指定股票对应的市场时，该股票代码在全市场中搜索。
其中，股东账号类型，仅支持’SHAccount’、‘SHBAccount’，’SZAccount’、’SBAccount’、’HKAccount’。不区分大小写
