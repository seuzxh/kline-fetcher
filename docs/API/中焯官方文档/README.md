## 与本项目代码的映射速查

**请求通道**：所有请求走 `GET {KLINE_API_BASE_URL}/reqxml?Action=...&outtype=1`（JSON 输出，HQP3 二进制协议由网关解码，响应键即属性英文名）。

**Action ↔ 代码**（定义见总览 v207，参数见通用业务接口 v197）：

| Action | 接口 | 项目实现 |
|---|---|---|
| 10000 | 通用属性（基础数据-多股票） | `get_stock_concept_plates`（关联属性 900/901/923）、`get_stock_info` |
| 10001 | 分时（trendtypes=-1 全时段） | `TrendFetcher`（CallTrend=46 集合竞价 / TrendOp=43 盘中 / 421~423 盘口） |
| 10002 | K线（klinetype=属性 ID） | `fetch_day_kline` / `fetch_min_kline` / `get_concept_plate_kline` |
| 10005 | 板块菜单（block.include 含板块指数时放首位） | `get_concept_plate_stocks` |
| 10007 | 板块指数排行（subtype=1 概念板块） | `get_all_concept_plates` |
| 未用 | 10003 成交明细 / 10004 分价量 / 10006 市场排行 / 10009 统计 / 10011 多市场筛选（filter 语法 `514,top 10`）/ 20700 市场信息 | — |

**K线属性 ID**（`klinetype` 取值 ↔ 响应键，见属性 ID 文档第 2 章）：
500=DayKLine、501=Min1KLine、502=Min5KLine、565/566/567=15/30/60 分钟、561=周、562=月 —— 对应 `_base.py` 的 `KLINE_TYPE_MAP` / `KLINE_RESPONSE_KEY_MAP`。

**值类型/单位换算**（属性 ID 文档 1.2 节，`_base.py` 的 `PRICE_SCALE`/`TURNOVER_SCALE` 依据）：

| val_type | 含义 | 放大倍数 | 项目换算 |
|---|---|---|---|
| 1 | 价格 | ×1,000,000（6 位小数） | `÷1e6 → 元` |
| 2 | 金额 | ×10,000（4 位小数） | `÷1e4 → 元` |
| 3 | 量 | 不放大，单位「股」 | 直通 |
| 4 | 比例 | ×1,000 | — |
| 5 | 百分比 | ×100,000 | 概念板块 `change_pct` 等原始字段未换算，用前 ÷1e5 |

**常用市场序号**：0=深证、1=上证、44=沪深板块指数（概念板块固定值）、103=北证。

**已验证的关键关联属性**（val_type=8，须配 `{propID}.props=0|1|2` 声明关联证券出参，缺省返回空对象）：
900=CoIndBlkIdx 隶属行业板块、901=CoBlkIdx 隶属全部板块、923=RegionBlkIdx 地域板块 —— `get_stock_concept_plates` 修复依据（2026-08-23）。

**官方约束**：单次 K线/分时/明细记录上限 **1500 条**（`download.py` 分段下载依据）；排行/列表类 `count` 上限 **100**（可配 200）；`enddate` 与 `daycount` 同时入参时 `daycount` 无效。
