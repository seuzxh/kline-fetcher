参数格式说明
入参说明
参数名
说明
复数
action
接口号

code
证券代码

codes
证券代码列表。格式：代码|市场序号

market
市场序号。详情查看：市场序号列表

routemarkets
分发市场序号列表，排行类接口必传。用于分发组件(MsHqToMultiServerPlus)进行拆分时使用，行情接入组件不使用此入参

props
证券属性ID列表。分隔符“|”

[propID].props
关联证券的证券属性ID列表。分隔符“|”，例：900.props=0|1|2

sort
排序证券属性ID。-1表示不排序，默认-1

direction
排序方向。0顺序，1倒序，默认1。sort属性排序时用。

start
查询起始位置。从0开始

count
查询数量。最大100

[propID].date
数据日期。例：620.date=20240412
1、查询某一日数据，格式YYYYMMDD2、默认为0，即查询当日数据3、只有存历史的属性才支持此查询，即props.ini中配置save_flag=1

[propID].daycount
数据查询天数。负数从date开始往前取N条，正数从date开始往后取N条，取当日数据传0，只有存历史的属性才支持此查询，例：620.daycount=-10

[propID].dayoffset
日期偏移值。自然数，获取的查询数据中偏移指定N日后的数据，默认0

[propID].locator
数组列表位置。第一条数据为0，列表入参类型为二进制流的Base64加密字符串，数组入参类型为整型，例：500.locator=AP////8=
列表：透传服务端返回的起止内容按需取起始或结束某一段，不传即取最新(即-1)，数组：不支持-1，默认值为0

[propID].count
数组列表查询数量。负数从locator开始往前取，正数从locator开始往后取，默认0，例：500.count=-20
列表：0无数据数组：0表示取locator往后所有

needtitle
是否需要返回标题。0不需要，1需要，默认0

langtype
语言类型。1简体，2繁体，3英文，默认1
langtype=2时应答中文都返回繁体，10005接口支持简/繁体板块名称并返回繁体数据；
langtype=1时应答中文都返回简体，10005接口只支持简体板块名称并返回简体数据；

outtype
输出格式类型。0普通，1Json。默认值0

trendtypes
分时属性列表。分隔符“|”。-1表示全交易时段，参数按各自属性分开返回

clientdate
客户端日期。如果clientdate和当前日期不一致，则返回全量数据

is_local
是否返回当地市场时间

klinetype
k线类型，即k线属性ID

klineunit
k线单位，只有日k、1分钟k时有效、默认1

cqtype
复权处理：0不做复权，1前复权，2后复权，默认0

detailtypes
成交明细属性列表。分隔符“|”。-1表示全交易时段，参数按各自属性分开返回

pricevoltypes
分价量属性列表。分隔符“|”。-1表示全交易时段，参数按各自属性分开返回

block
板块名称

block.type
板块查询类型。0-按板块名称代码，1-按板块指数代码，2-按虚拟板块名称查询，虚拟板块存在行情中心，首次在美股期权榜单中使用。默认0

block.include
是否包含对应的板块指数。0不包含，1包含，默认值1。block.type=0时，此参数无效。

klineindexs
k线指标，用于返回K线图副图指标数据。多个指标可用 | 分割
目前支持的K线指标属性ID列表如下
800-大单净量
801-大单净额
5182~5191-神奇九转指标，华泰用


nokline
1-不处理k线数据，仅用于10002接口其他接口无效。主要用于查询指标属性值时使用。
0-处理k线数据，默认值。

ind_date
格式：yyyymmdd，k线指标开始日期，从最新行情日期查询可传99999999。nokline=1时为必传

ind_date_end
格式：yyyymmdd，k线指标结束日期。ind_date_end和ind_count同时入参时，ind_date_end优先级高。 nokline=1时为必传

ind_count
指标数量，负数从ind_date开始往前取N条，正数从ind_date开始往后取N条。ind_date_end和ind_count同时入参时，ind_count优先级低。nokline=1时为必传

index_belong
所属指数信息，格式为code|market。用于请求569、570属性，计算时需要获取所属指数的流通市值进行计算。

begindate
格式：yyyymmdd，k线指标开始日期。 用于请求500日k属性。

enddate
格式：yyyymmdd，k线指标结束日期。enddate和daycount同时入参时，daycount入参无效。用于请求500日k属性。

daycount
指标数量，负数从begindate开始往前取N条，正数从begindate开始往后取N条。enddate和daycount同时入参时，daycount入参无效。用于请求500日k属性。

filteramount
过滤金额，单位“元”。用于10003明细接口对返回的明细记录成交额进行筛选返回，成交量*成交价&gt;=filteramount即满足筛选条件。

ind_outtype
指标属性返回格式，主要针对基础类型属性，如int，int64，默认0。
ind_outtype=0：ind和dayindex分开返回，默认格式，以json为例：
ZJLXNetTur.ind=[[-90775520000,-398239520000,-316619440000,-206574000000,-107690970000,312796860000,-388059640000,-70256980000,27430260000,0]]620.dayindex=[[[20231020,1],[20231023,1],[20231024,1],[20231025,1],[20231026,1],[20231027,1],[20231030,1],[20231031,1],[20231101,1],[20231102,1]]]
ind_outtype=1：ind和dayindex日期合并返回：
ZJLXNetTur.ind=[[[20231020,-90775520000],[20231023,-398239520000],[20231024,-316619440000],[20231025,-206574000000],[20231026,-107690970000],[20231027,312796860000],[20231030,-388059640000],[20231031,-70256980000],[20231101,27430260000],[20231102,0]]]

PS：
未有明确标注分隔符的复数入参值，均以半角逗号“,”进行分隔；
[propID]表示可变名称，请求应答以实际证券属性ID为准；
股票分页请求时，如10000、10005、10006等多股票接口，最大股票数限制最大值，默认100，最大支持配置max_page_size=200，相关入参如count；
最大记录请求是，如分时、明细、k线等属性请求数量时，最大记录数限制最大条数为1500，不支持配置，相关入参如：[propID].count，[propID].daycount，daycount，ind_count等；

filter
String

筛选条件，即按什么字段选股和相应的参数，空为不筛选 筛选是基于个股属性的筛选，非市场属性；
条件类型约定：
序号
条件类型
条件符号及说明
用法
1
范围查询(int、int64、float)
(a) 在某个范围不含边界值：符号()， 双操作数，只发一个操作数说明另一个没限制(b) 在某个范围含边界值：符号[], 双操作数，只发一个操作数说明另一个没限制
1300,(1,3) 含义：1300属性 1&lt;value&lt;31300,[1,3] 含义：1300属性 1&lt;=value&lt;=31300,(,3) 含义：1300属性 value&lt;31300,(0,) 含义：1300属性 0&lt;value
2
值匹配查询(int、int64、float、string)
符号{},匹配符合花括号内任一个值的项，无论哪种类型都支持多值匹配；字符串类型需要完全匹配，区分大小写。
1300,{1,2,3,4} 含义：只要1300的值是1或2或3或4则匹配1300,{AAPL} 含义：只要1300的值是AAPL则匹配，字符串类型区分大小写1300,{1.2,2.3} 含义：只要1300的值是1.2或2.3则匹配
3
top查询(int、int64、float)
符号top,筛选数值类型属性的排名前几或者倒数前几
10,top 5 含义：10属性排名前5的记录
10,top -5 含义：10属性排名倒数前5的记录
注意：
(1)top和名次之间用空格分开，top和之前的逗号之间不要有空格
(2)属性值为Null的时候，不参与排名，初始化阶段top的结果可能是空

条件组合：
序号
条件组合
说明
用法
1
且查询：|
|连接的两个条件同时满足才符合
筛选涨跌幅前10且市值前5的股票：514,top 10 | 550,top 5
2
或查询：or
or连接的条件有一个满足，则符合
筛选涨跌幅前10或市值前5的股票：514,top 10 or 550,top 5
优先级：| &gt; or

复杂用法：
（1）或和且的变化组合，一定可以转化成n组的或条件，形如 A1 or A2 or A3... ，其中A1、A2、A3可以是一个条件，或者是多个且条件组合
比如筛选： (A=1 或 B=2) 且 (C=3) 等价于 (A=1且C=3) 或 (B=2且C=3)；传参的时候传 A=1|C=3 or B=2|C=3 传参的时候，一定不带括号

注意：单位和3.0属性单位一致。
说明：
1、对于某项条件，如果输入的属性在市场中未配置，则该条件对于该市场所有股票都不匹配。
2、对于某项条件，如果输入的操作数超出范围、或者不合法，该条件作废，不返回结果，提示筛选条件有误；比如 数字型操作符传了字符串 1300,(AAA, BBB)
3、对于某项条件，如果输入的操作符不能正确识别或者操作符混合的情况，则该条件作废，不返回结果，提示筛选条件有误；比如 1300,{123]或者1300,[0,100)；
4、没有发操作数，则该条件无效；比如1300,[]或1300,{}；该条件作废，不返回结果，提示筛选条件有误
5、多条件输入，只要出现一个条件非法时，不返回结果，提示筛选条件有误；
6、筛选功能只支持属性普通类型，这些类型的属性不支持：list、array、linklist、null；
7、对于范围查询的操作数a,b 要求a&lt;=b，否则该条件不合法；
8、退市代码不参与筛选，筛选时默认过滤掉退市代码
